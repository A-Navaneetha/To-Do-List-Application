A modern, responsive, and user-friendly **To-Do List Web Application** built with **HTML**, **CSS**, and **JavaScript**. The application helps users efficiently manage their daily tasks with features such as adding, editing, deleting, filtering, and storing tasks using the browser's Local Storage.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/ToDo-App.git
```

### 2. Open the Project

```bash
cd ToDo-App
```

### 3. Run the Application

Simply open the `index.html` file in your browser.

Or, if you're using Visual Studio Code:

* Install the **Live Server** extension.
* Right-click `index.html`.
* Select **Open with Live Server**.

---

## 💻 How to Use

1. Enter a task in the input field.
2. Click **Add Task** or press **Enter**.
3. Mark tasks as completed using the checkbox.
4. Edit tasks using the edit button.
5. Delete unwanted tasks.
6. Filter tasks using **All**, **Active**, or **Completed**.
7. Click **Clear Completed** to remove completed tasks.
8. Refresh the page—your tasks remain saved automatically.
